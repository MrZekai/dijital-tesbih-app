# Zikirmatik

Android için dijital tesbih ve tarayıcıda çalışan zikir sayacı.

[Türkçe sayaç](https://zikirmatik-mrzekai.web.app/tr/) · [English](https://zikirmatik-mrzekai.web.app/en/) · [العربية](https://zikirmatik-mrzekai.web.app/ar/) · [Google Play](https://play.google.com/store/apps/details?id=com.zikirhane.tesbih)

Android uygulaması [frontend](frontend/) klasöründedir. [Odak sayaç ekranı](frontend/app/%28tabs%29/index.tsx) günlük ilerlemeyi, seçili zikri, dokunarak sayma alanını ve hedefe kalan sayıyı gösterir. Diğer sekmeler zikir listesine, geçmişe ve ayarlara erişim sağlar.

Web sitesi için [Firebase Hosting ve PowerShell yayın rehberini](site/README.md) kullanın.
